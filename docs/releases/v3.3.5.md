## 更新内容

- **机器占用不贴边**：收起条正在轮播处理器、内存、网速这些读数时，现在可以让小岛先别缩回屏幕边上。在 设置 → 通用 → 贴边隐藏 里勾选「机器占用时不贴边」即可；和已有的三个开关一样，它只暂停收起状态的自动贴边，活动结束后照常等待设定的时间。

## What's new

- **Counters stay out**: while the collapsed bar is cycling through the processor, memory and network readings, the island can now stay put instead of tucking back to the screen edge. Tick "Stay out while the counters show" under Settings → General → Tuck when idle. Like the three switches beside it, it only holds the idle tuck and the usual wait resumes afterwards.
