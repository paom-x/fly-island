## 更新内容

- **机器占用**：收起的小岛现在能显示整机读数——处理器、内存、网速、显卡（这台电脑读得到的才列出来），每 4 秒换一项。在「设置 → 外观 → 机器占用」里点选要看哪几个，一个都不点就不显示。
- **通知只看未读**：「设置 → 消息」新增「通知内容」。选「只看未读」就完全不读发送者和正文，岛上只说收到新消息；选「读取内容」则照旧显示发送者和一行正文。两种方式都只在内存里，不写磁盘、不进历史。
- **OLED 防烧屏**：收起的小岛每 3 分钟沿屏幕顶边挪 1~2 像素，避免同一列像素长时间常亮，平时察觉不到。默认打开，「设置 → 通用 → 位置」里可以关。
- **更省资源**：QQ 通知监听改为常驻并由系统事件唤醒、读列表不再是每秒一次（没有打包身份的调试版订阅不到事件时退回每秒读取，不漏消息）；跟随显示器的循环直接问 Windows 要坐标，不再占用主线程；指针离开岛后光标轮询从 12 毫秒放宽到 50 毫秒；面板收起时不再给只有展开页才用的计时器建定时任务。
- **修复**：调试版（未打包）此前会显示「Windows 通知监听不可用」并漏掉 QQ 消息，现已退回每秒读取。

## What's new

- **Machine load**: the collapsed island can now show whole-machine readings — processor, memory, network speed, graphics (only the ones this computer can read) — changing every four seconds. Pick the ones to watch in Settings → Appearance → Machine load; with none picked the line stays off.
- **Unread only**: Settings → Messages gained "Notification text". "Only unread" reads neither the sender nor the text, so the island just says something arrived; "Read content" keeps showing the sender and a line of it as before. Either way it lives in memory only — no disk, no history.
- **OLED burn-in guard**: every three minutes the collapsed island steps one or two pixels along the top edge, so one column of pixels is not lit for hours. The step is meant to be invisible. On by default; Settings → General → Position turns it off.
- **Lighter**: the QQ notification listener now stays resident and is woken by system events, so the notification list is no longer read every second (a debug build, which cannot subscribe to the event, falls back to one read a second and still catches everything); the monitor-follow loop asks Windows for the monitor rect instead of going through the runtime main thread; cursor polling relaxes from 12 ms to 50 ms once the pointer leaves; and the collapsed panel no longer schedules timers that only the expanded pages use.
- **Fixed**: an unpackaged build used to show "Windows notification listener unavailable" and miss QQ messages; it now falls back to one read a second.
