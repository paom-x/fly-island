## What's new

- **Z Code support**: The status light, the session list and usage now work. Sessions are read from Z Code's own store, so running, finished and waiting sessions show up on the island, and running a command or editing a file can be approved right on the island (only while Z Code is in its confirm-before-changes mode).
- **Memory**: The WorkBuddy sign-in window is destroyed when idle instead of staying resident, the collapsed island hands the browser's working set back to Windows, and the quick translation window is created on first use instead of at startup.
- **Settings**: The status table on the Connect AI tools page now also lists DeepSeek Harness and WorkBuddy; their state comes from local sessions, so no hooks are needed.

## Downloads

- `fly-island_3.3.2_x64-setup.exe`: Windows x64 EXE installer.
- `fly-island_3.3.2_x64_en-US.msi`: Windows x64 MSI installer.
